# Contributing

Thanks for helping improve voltdex.

## Licensing of contributions

voltdex is licensed under the [MIT License](LICENSE). By submitting a pull request,
you agree that your contribution is licensed under the same MIT License
("inbound = outbound").

Please sign off every commit (`git commit -s`). The sign-off certifies the
[Developer Certificate of Origin 1.1](https://developercertificate.org/): that you wrote
the change, or otherwise have the right to submit it under the project's license.

## No Pokémon artwork in the repository

Do not add Pokémon artwork, sprites, or other game assets to the repository. The tool
downloads images at runtime instead; see [NOTICE.md](NOTICE.md).

## Before opening a pull request

- `npm test` passes.
- New behaviour comes with a test.
